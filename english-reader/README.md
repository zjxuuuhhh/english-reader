# 📖 英语朗读 · English Reader

一个**纯本地**的英语朗读网站：导入英文文本 → 整篇朗读 / 逐句朗读 / 点词发音，音质贴近真人。

无需安装依赖、无需联网账号即可使用（Edge 语音模式）。所有文本、生词、历史都保存在你自己的浏览器里。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 📥 导入文本 | 粘贴到文本框，或上传 `.txt` 文件 |
| ▶ 整篇朗读 | 逐句连续朗读，当前句高亮 + 自动滚动，支持暂停/继续/上一句/下一句 |
| 🔤 逐句朗读 | 点击任意句子左侧的 ▶，只读这一句（适合跟读模仿） |
| 🖱 点词发音 | 打开「点词发音」开关后，**单击任意单词立即发音** |
| 🔁 单句循环 | 当前句播完自动重播，适合反复跟读 |
| 📓 生词本 | 阅读时**双击单词**收藏，生词本里可点击听音、删除、手动添加 |
| 🕘 学习历史 | 导入过的文本自动保存（最近 20 条），一键载入 |
| 🌙 深色模式 | 一键切换，自动记住 |
| ⚡ 音频缓存 | 合成过的句子本地缓存，重复播放秒出声、断网也能重听 |

## 🚀 两种启动方式

### 方式一：直接打开（最简单）

**双击 `index.html`**（推荐用 Edge 或 Chrome 打开）。

- ✅ Edge 神经语音模式开箱即用（免费、无需任何配置）
- ⚠️ OmniVoice 模式需要服务端允许跨域；不支持时请用方式二

### 方式二：本地代理（推荐，功能最全）

需要安装 [Node.js](https://nodejs.org)（本机已装 v20）：

```bash
node server.js
```

然后浏览器打开 **http://127.0.0.1:8765**

- ✅ OmniVoice 请求经本地代理转发，不受跨域限制
- ✅ 阅读体验与方式一完全相同

## 🔊 音源说明

顶部工具栏可随时切换两种音源：

### 1. Edge 神经语音（默认）

微软 Edge「大声朗读」背后的新一代神经网络语音（**不是** Windows 那种机械 SAPI 读音），
16 个英文音色可选：Ava / Andrew / Emma / Brian（最自然的几个）、Sonia / Ryan（英音）等。
完全免费、无需 Key、无需配置。

### 2. OmniVoice（你自己的 API）

点「⚙️ 设置」填写：

| 配置项 | 说明 |
|---|---|
| Base URL | 服务地址，如 `https://api.xxx.com` 或 `http://127.0.0.1:8880` |
| API Key | 留空则不发送 Authorization |
| 模型名 | 默认 `k2-fsa/OmniVoice` |
| 音色 Voice | `auto` 或你服务支持的音色名 |
| 额外参数 | 可选 JSON，合并进请求体（如音色克隆参数） |
| 模式 | 浏览器直连 / 经本地代理（推荐） |

接口走 OpenAI 兼容格式：`POST {Base URL}/v1/audio/speech`，请求体
`{ model, input, voice, response_format: "mp3", speed }`。填完点「🔌 测试连接」会合成一句试听。

> 💡 **AMD Radeon Cloud（OmniVoice）示例**：Base URL 填
> `https://developer.amd.com.cn/radeon/api/v1`（已自动适配其 `/v1` 路径规则），
> 模型名 `OmniVoice`，音色留 `auto`，粘贴 API Key 后测试即可。
> 想定制音色可在「额外参数」里加 `{"instructions":"male, low pitch, british accent"}`（文字描述音色）。

### Edge 语音的连接策略

1. **优先浏览器直连**微软服务（免费、无需启动任何东西）
2. 直连失败时**自动回落**到本地代理（需已运行 `node server.js`）
3. 两种路径都已实现微软新一代 v2 鉴权（Sec-MS-GEC），与官方参考实现逐字节一致

## ❓ 常见问题

- **点击朗读没声音？** 浏览器可能拦截了自动播放，再点一次播放按钮即可；另外确认系统音量。
- **Edge 语音提示连接失败？** 该服务需要联网；公司内网可能屏蔽 `speech.platform.bing.com`。
- **单词点击没反应？** 检查顶部「点词发音」开关是否打开。
- **双击单词没收藏？** 双击 = 收藏生词，单击 = 发音，注意区分。
- **想换音色？** 顶部下拉随时切换；切换后新的朗读使用新音色（旧缓存按音色分开保存）。
